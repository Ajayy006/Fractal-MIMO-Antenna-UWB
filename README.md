# Design and Fabrication of a Wideband Fractal MIMO Antenna with T-Shaped Isolation Structure for UWB and High-Speed Wireless Applications

## 📌 Project Overview

This project focuses on the design, simulation, and fabrication of a wideband fractal Multiple-Input Multiple-Output (MIMO) antenna incorporating a T-shaped isolation structure. The antenna is intended for Ultra-Wideband (UWB) and high-speed wireless communication applications.

The antenna design is developed and analyzed using Ansys HFSS, an electromagnetic simulation tool. After simulation, a physical prototype is fabricated to study its practical implementation and performance.

## 🎯 Objectives

* To design a wideband fractal antenna for UWB applications.
* To analyze antenna characteristics using Ansys HFSS.
* To incorporate a T-shaped isolation structure to reduce mutual coupling between antenna elements.
* To fabricate a physical prototype of the proposed antenna.
* To evaluate antenna performance through simulation and hardware measurements.

## 🛠️ Tools and Technologies

* **Simulation Software:** Ansys HFSS
* **Design Type:** Fractal MIMO Antenna
* **Isolation Technique:** T-Shaped Isolation Structure
* **Substrate:** FR-4
* **Fabrication:** Physical antenna prototype fabrication

## 📐 Antenna Design

The proposed antenna uses a fractal geometry to achieve wideband characteristics. A T-shaped isolation structure is incorporated into the MIMO configuration to improve isolation between antenna elements.

The design dimensions and final antenna geometry are provided in this repository.

## 📊 Simulation and Analysis

The antenna is analyzed using Ansys HFSS to evaluate its electromagnetic performance.

The following parameters can be included based on the results obtained:

* **Reflection Coefficient (S11):** Evaluates impedance matching.
* **Mutual Coupling (S21):** Evaluates coupling between antenna ports.
* **Impedance Bandwidth:** Determines the frequency range of operation.
* **Gain:** Evaluates the antenna's directional radiation performance.
* **Radiation Pattern:** Shows the antenna's radiation characteristics.
* **Envelope Correlation Coefficient (ECC):** Evaluates diversity performance, if calculated.
